# Bridge AI 使用教程 - 视频规格

## 1. 视频基本盘

- 标题：Bridge AI 使用教程
- 目的：让完全没用过 AI 工具的小白，在 90 秒内理解 Bridge AI 的核心价值，并知道如何完成"配置模型 → 管理应用 → 开始对话"三步操作
- 受众：完全没用过 AI 工具的小白，可能是刚接触 ChatGPT、Claude 等工具的初学者，对 API Key、模型供应商等概念不熟悉
- 观众熟悉度：不要预设观众懂 API Key、Base URL、模型供应商等术语；需要从"统一管理"这个痛点切入，逐步解释
- 平台与时长：Bridge AI 应用内嵌教程，总时长 90 秒
- 画面规格：16:9 横屏，30fps，需要无声播放友好（必须有逐词字幕）
- 输出：mp4，1080p
- 核心信息：Bridge AI 让使用 AI 变得更简单
- 信息密度：教程型节奏，每个步骤讲清楚，不追求 hook 型高密度
- 语气基调：友好引导式，像一个耐心朋友在手把手教；不要专业说教感、不要营销广告感


## 2. 叙事结构

- 叙事节拍：
  1. Hook（0–5s）：抛出小白用 AI 的痛点
  2. 问题 → 解决方案（5–20s）：多个 AI 工具混乱 → Bridge AI 统一管理
  3. 核心三步演示（20–65s）：
     - 配置模型（20–35s）
     - 管理应用（35–55s）
     - AI 对话（55–65s）
  4. 高级能力（65–85s）：技能商店、会员功能
  5. CTA（85–90s）：打开 Bridge AI，开始体验
- 情绪曲线：困惑 → 清晰 → 跃跃欲试
- 音画关系：氛围性 BGM，旁白主导画面；一处音画错位：讲到"统一管理"时，画面展示多个分散的 AI 工具图标被收纳进 Bridge AI 中心
- 同质化反例：
  - 视觉：不要卡通插画、emoji、花哨渐变背景
  - 叙事：不要 countdown 倒计时、不要过度煽情
  - 节奏：不要全程快节奏 hook，要让观众能跟上每一步


## 3. 表达手段

- 场景类型组合：UI 模拟录屏（60%）+ 文字标题卡片（25%）+ 图标动画（15%）
- 字幕呈现：逐词卡拉 OK 式字幕，当前读到的词高亮
- 关键词强调：需要，高亮"API Key"、"统一管理"、"一键启动"、"技能商店"
- 文字动效：标题用打字机效果；关键词用弹出/放大高亮
- 3D：不需要
- 转场风格：平滑滑动过渡为主（70%），硬切为辅（30%）
- 特殊视觉：聚焦高亮框跟随鼠标/操作位置；数据流光线装饰；成功状态绿色对勾动画
- 节奏基准：平均 2.5–3.5 秒一镜，90 秒约 25–28 个镜头；中文旁白约 230–260 字


## 4. 视觉规范

- 视觉主题：Data Drift
- accent 色：#00D4FF → #7C3AED 渐变（Bridge AI 品牌色）
- 装饰密度：中等 — 加入 hairline、角标、轻微数据流装饰，既有科技感又不干扰信息阅读
- 组件取舍：绝对不要用卡通插画组件、emoji 组件、3D 小人组件


## 5. 素材清单

### 已有素材

无。所有素材需要生成或模拟。

### 待生成素材

- TTS 旁白：使用本地 TTS 生成完整旁白，导出为 `audio/voiceover.wav`
- 字幕文件：基于旁白生成逐词时间轴，导出为 `subtitles/captions.srt`
- UI 模拟画面：基于 Bridge AI 界面结构生成模拟录屏/截图，导出到 `assets/ui-mockups/`
- Bridge AI Logo：使用项目现有 logo 资源，路径 `assets/logo/logo-horizontal.svg`

### 待搜索素材

无搜索素材需求。所有视觉元素均可通过 UI 模拟和程序生成实现。

# Bridge AI — 需求规范 (Spec)

## 1. 产品概述
Bridge AI 是一个基于 Tauri（Rust + Web）的桌面应用，作为 AI 模型统一配置管理中枢。面向 AI 初学者，提供模型配置管理、工具集成、内置 AI 对话、技能商店和高级会员功能。

## 2. 功能需求

### 2.1 首次启动向导
- 4 步配置流程：欢迎 → API Key 录入 → 模型选择/测试 → 完成
- 支持跳过直接使用
- 配置完成后自动创建初始模型

### 2.2 工具集成 (ToolsView)
- EchoBird 风格三栏布局：工具卡片网格（左）+ 搜索/筛选（顶部）+ 详情面板（右）
- 自动检测已安装的 AI 工具（ChatGPT Desktop、Cursor、Claude Desktop 等）
- 支持一键安装未安装的工具
- 支持同步模型配置到已安装工具
- 操作日志显示

### 2.3 技能商店 (SkillMarket)
- 技能卡片网格展示
- 按分类/搜索过滤
- 详情面板展示技能信息
- 安装/卸载功能
- 会员用户可下载高级技能

### 2.4 AI 对话 (Chat)
- 多轮连续对话
- 流式输出
- 粘贴复制消息功能
- 模型选择切换
- 新建会话
- 消息计数

### 2.5 模型管理 (Models)
- 模型供应商目录展示
- 添加/删除模型
- 更新 API Key
- 测试连接
- 支持 OpenAI/DeepSeek/Ollama/自定义

### 2.6 高级会员 (PremiumView)
- 29.9 元/年订阅
- 7 天免费试用
- 激活码激活
- 功能列表展示
- 会员状态显示

### 2.7 设置 (Settings)
- 主题切换（深色/浅色）
- 字体大小调节
- 最大上下文设置
- 关于信息

## 3. 技术栈
- 前端：React + TypeScript + Vite + React Router
- 后端：Tauri (Rust)
- 样式：纯 CSS（EchoBird 风格深色主题）
- 状态管理：Zustand (appStore)

## 4. 界面规范
- 左侧固定宽度侧边栏（220px）
- 右侧内容区域
- 深色主题：#0D0D15 背景
- 主色：#7C3AED（紫色）
- 强调色：#00D4FF（青色）
- 所有页面使用 EchoBird 卡片式布局

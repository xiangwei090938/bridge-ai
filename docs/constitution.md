# Bridge AI — 项目纲领 (Constitution)

## 项目使命
为 AI 初学者提供一个统一的模型配置管理与工具集成的桌面中枢，降低 AI 工具使用门槛。

## 核心原则

### 1. 初学者优先
- 所有设计以 AI 初学者体验为第一优先级
- 首次启动向导式配置，无需了解复杂概念
- 界面文案全中文，操作直观

### 2. 代码质量
- Rust 后端：分层解耦（core/service/command/util）
- 前端：按页面隔离路由，公共组件抽离复用
- 模块化约束：单模块单职责，禁止跨层导入

### 3. 用户体验
- 首次启动 4 步向导（欢迎→密钥→模型→完成）
- 内置 AI 聊天面板，支持流式输出
- 深色/浅色主题
- 所有页面严格按照 EchoBird 卡片式布局克隆

### 4. 安全优先
- API Key 使用系统密钥链存储（Windows Credential Vault / macOS Keychain）
- 无明文密钥写入日志或本地文件
- 技能商店沙箱隔离

### 5. 商业模式
- 基础功能免费
- 高级功能（技能商店下载等）需会员订阅
- 会员 29.9 元/年

- 前端严格克隆 EchoBird 的每个页面 UI 风格
- 所有面板保持极简交互，减少不必要的弹窗
